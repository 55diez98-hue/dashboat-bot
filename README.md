# Dashboat v3 — Telegram барахолки Батуми

Совместимая замена исходной сборки на `simple_server.py` + `telegram_monitor.py`.

## Загрузка на GitHub

Загрузите **в корень репозитория** файлы из этой папки: `simple_server.py`,
`telegram_monitor.py`, `storage.py`, `requirements.txt`, `render.yaml`, `Procfile`, `README.md`.
Не загружайте ZIP вместо отдельных файлов, если Render собирает репозиторий.
Исходные файлы можно восстановить из GitHub → Commits.

## Render: переменные Environment

Не помещайте секреты в GitHub. Проверьте существующие `API_ID`, `API_HASH`,
`SESSION_STRING`, `BOT_TOKEN`, `ALERT_CHAT_ID`. Добавьте `ADMIN_PASSWORD` — длинный
случайный пароль для панели. Вход: логин `admin`, пароль `ADMIN_PASSWORD`.
Не удаляйте текущие переменные/настройки UptimeRobot.

Опционально добавьте `DATABASE_URL` — строку подключения PostgreSQL. Она нужна,
чтобы группы, ключевые слова и история дублей **гарантированно переживали**
перезапуски/деплои Render Free. Без неё используется прежний локальный
`dashboat_data.json`: он сохраняется при обычном перезапуске процесса, но
на Render Free может пропасть при redeploy или смене экземпляра. Ранее
существовавший локальный JSON автоматически импортируется при создании пустой БД,
если файл доступен в момент первого старта с БД.

## Адреса

- `/` и `/ping` возвращают HTTP 200 для UptimeRobot; существующий URL проверки `/`
  менять не требуется.
- `/dashboard` — защищённая панель администратора (Basic Auth).
- `/health` — JSON состояния Telegram и HTTP 503, если Telethon не работает.

## Изменения

- Реальная остановка/перезапуск подключения Telethon.
- Группы и ключи обновляются после нажатия «ПЕРЕЗАПУСТИТЬ».
- Названия доступных групп подгружаются при подключении.
- HTML-экранирование уведомлений, ссылки на публичные/частные группы.
- Межгрупповая дедупликация точных текстов и очень близких длинных текстов;
  хранение истории в течение 14 дней (до 3000 сообщений).
- Счётчики и последнее полученное сообщение — за текущий процесс.

## Ограничения

Дедупликация сравнивает тексты, **не картинки**. Однотипные объявления с
существенно разным текстом могут проходить повторно. В редких случаях похожие
длинные объявления могут ошибочно определяться как дубли. Она применяется к
новым сообщениям; история уже опубликованных объявлений не сканируется.
Статус HTTP 200 от UptimeRobot показывает только работу веб-процесса.
Выполнение проверено статически; Telegram и Render требуют проверки после деплоя.
