# Dashboat v3.2 + Android API — серверное обновление

Этот ZIP предназначен **только для GitHub-репозитория `dashboat-bot`**, связанного с Render. Android-приложение `dashboat-android` повторно собирать не требуется.

## Что меняется

- Добавлены защищённые `GET /api/v1/state` и `POST /api/v1/command` для текущего APK.
- Состояние, группы, ключевые слова и история читаются из того же хранилища, что веб-панель `/dashboard`.
- Управление стартом/остановкой/перезапуском вызывает те же функции сервера, что и веб-панель.
- Межгрупповые дубли подавляются 14 дней; повторы в той же группе — 72 часа (существующая логика сохранена без изменения).
- У `POST /api/v1/command` добавлена проверка Origin для запросов из браузера.
- UptimeRobot `/` и `/ping` сохраняют публичный HTTP 200.
- PostgreSQL не требуется и не включается; при отсутствии `DATABASE_URL` используется локальный JSON. На Render Free его данные могут исчезнуть при redeploy.

## Перед загрузкой

1. Сохраните текущий список ID групп, ключевых слов и нужную историю **из панели**, поскольку Render Free может очистить локальный JSON при развёртывании новой версии.
2. Убедитесь, что в Render задана переменная `ADMIN_PASSWORD` (не публикуйте значение). Остальные секреты не включены в ZIP.
3. Не изменяйте настройки UptimeRobot.
4. Сохраните ссылку на предыдущий рабочий коммит GitHub, чтобы при необходимости можно было откатиться.

## Установка

1. Распакуйте ZIP.
2. В репозитории `dashboat-bot` откройте **Add file → Upload files**.
3. Перетащите **содержимое папки**, а не ZIP. Если GitHub предложит заменить файлы, подтвердите, затем **Commit changes** в `main`.
4. Render автоматически задеплоит изменения, если подключено автодеплой-развёртывание.
5. Сначала откройте https://dashboat-bot.onrender.com/ — должен быть HTTP 200.
6. Откройте https://dashboat-bot.onrender.com/api/v1/state в приватной вкладке. Должен появиться запрос логина и пароля или ответ `401` (это означает, что API-маршрут найден и защищён). Через Android-приложение с существующими `admin` и `ADMIN_PASSWORD` должен загрузиться список групп.
7. Проверьте в `/dashboard` списки групп и слов, статус Telegram, отправку нового алерта; при пропаже настроек восстановите списки из своей резервной копии.

## Локальные тесты (без реального Telegram)

`python -m unittest discover -s tests -v`

15 тестов выполнены успешно в среде подготовки. Действительное подключение к Render/Telegram из тестов не проверяется; итог проверяется после развёртывания.

## Файлы

- `simple_server.py`: веб-интерфейс и два новых API-маршрута.
- `telegram_monitor.py`, `storage.py`: без изменений относительно v3.2.
- `requirements.txt`, `render.yaml`, `Procfile`: без изменений относительно v3.2.
- `tests/test_dashboat.py`: исходные и дополнительные тесты API.
- `README.md`: прежние инструкции.
- `groups_to_add.txt`: список 14 групп (загружать в панель вручную при необходимости).
